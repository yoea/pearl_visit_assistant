# 珍珠生走访审核辅助平台

新华教育基金会内部工具：将候选珍珠生 Excel 在**本地浏览器**中完成读取、清洗、脱敏，
再将脱敏数据交由 AI（DeepSeek 直连）生成「走访参考报告」。

## 功能总览（v1.1.0）

| 模块 | 说明 |
|---|---|
| 导入 | 拖拽/点击上传 `.xlsx/.xls`，自动识别表头（含系统导出文件：表头第 6 行、子表头行自动跳过），自动提取学校名称与届别（期数 → 珍珠班编号尾段如 `滇-11-26` → 资助项目名如 `2026级…`） |
| 脱敏及检查 | 本地自动脱敏 + 三道安全检查；数字校验卡提前提示易错字段（身高/体重/收入/负债的单位常识问题）；确认后手动开始 AI 分析，绝不自动发送 |
| AI 分析 | DeepSeek 直连（分批并行），提示词含申请理由一致性/经济困难真实性/数据合理性三重交叉验证；token 用量统计（本次 + 本机累计） |
| 报告 | 卡片化分模块展示（学校整体 + 单学生卡片），异常字段琥珀标注；可下载 Markdown / 单文件 HTML（零外部资源）；自动存档到本浏览器 30 天（未访问自动过期），主页列表可查看/删除 |
| 辅助 | 步骤条可点击跳转；报告页本地姓名查找（实时下拉 + 学生信息模态框）；分析完成庆祝动画；帮助页；页脚快速菜单（项目管理平台/基金会官网） |

## 隐私承诺（最高优先级）

- 原始学生数据（姓名/身份证/电话/QQ/微信/邮箱/详细地址/教师姓名/珍珠号等）**绝不出本机**；
- Excel 文件绝不上传；发送 AI 前先脱敏，再经强制安全检查，命中即阻止且不可绕过；
- localStorage 仅两类**用户授权的有限放宽**：① token 计数数字 ② 报告存档（含姓名映射，仅本机、30 天过期自动删除）；均由 `tests/no-persistence.test.ts` 静态守卫白名单锁定；
- 本仓库 `examples/` 下的真实数据文件已被 .gitignore 排除，绝不进入版本库或测试。

## 部署形态：x96max 局域网

页面托管在办公室局域网设备（x96max / Armbian，零依赖 `node static-server.mjs`），
同事浏览器访问 `http://<设备IP>:80`；脱敏在浏览器本地完成，分析直连 DeepSeek——
**局域网可信环境决策：API Key 随构建注入页面产物（用户明确授权，Key 泄露时重置即可）**。
部署步骤见 [`server/README.md`](server/README.md)。

### 环境变量（构建期注入）

| 变量 | 说明 | 默认 |
|---|---|---|
| `VITE_ANALYSIS_PROVIDER` | `mock`（本地规则引擎）或 `real`（真实 AI） | `mock` |
| `VITE_DEEPSEEK_API_KEY` | DeepSeek API Key（real 时必填） | 空 |
| `VITE_DEEPSEEK_MODEL` | 模型名 | `deepseek-v4-flash` |
| `VITE_ANALYSIS_TIMEOUT_MS` | 请求超时毫秒数 | `60000` |
| `VITE_APP_TITLE` | 页面标题（浏览器标签页/页眉/首页） | `珍珠生走访审核辅助平台` |
| `VITE_APP_SUBTITLE` | 副标题（功能说明，首页标题下方） | 见 `.env.example` |
| `VITE_USAGE_REPORT_URL` | 使用统计上报接口（可选；未配置则完全不发送） | 空 |

- `real` 但未配置 Key 时自动回退 Mock 并在控制台提示。
- 可复制 `.env.example` 为 `.env` 按需修改（`.env*` 已被 gitignore，`.env.example` 除外）。
- 改动标题/副标题后需重新构建才生效。

### 使用统计上报（可选）

配置 `VITE_USAGE_REPORT_URL` 后，打开工具 / 分析成功 / 分析失败时会向该接口
POST **白名单计数**（工具名、版本、随机浏览器 ID、事件、学生人数、token 数字），
**绝不包含任何学生数据**；未配置则完全不发送。接口契约见
[`docs/usage-report-api.md`](docs/usage-report-api.md)（供后端实现）。

## 发送前确认（安全红线）

安全检查通过后必须手动点击「确认并开始 AI 分析」才会发送；绝不自动发送。
AI 不是资格审批器（严禁「通过/淘汰」类结论）；事实与推测分离，推测仅以「推测：」标注。
